Welcome to AVAP-OS — a lightweight, aesthetic web operating system built right inside your browser! It gives you a full desktop workspace complete with window management, top navigation, dynamic apps, and a smooth translucent dock.

✨ Features
Desktop & Translucent Dock: A macOS-inspired translucent dock sitting over a pixel-art wallpaper.

Top Bar with Live Clock: Displays system controls, menus, and a real-time clock.

Draggable & Stackable Windows: Drag windows around your screen with focus management so active windows automatically pop to the front.

App Ecosystem:

Welcome / About Modal: Intro screen with persistent state saved via localStorage.

AVAPnotes: Dynamic notes app with a sidebar layout driven by JavaScript data structures.
